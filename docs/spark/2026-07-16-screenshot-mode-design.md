# 截图模式 v1 —— 设计稿（Ringgo × CleanShot）

> 2026-07-16 定稿（经四路规格自审修订：一致性 / 歧义 / 决策还原度 / 可实现性）。
> 目标：让 Ringgo 承担日常截图工具职责（替代 CleanShot X 的核心工作流），
> 并把圈选搜索的智能反向注入截图链路。滚动截图、录屏/GIF 为后续独立 spec（见 §12）。
> 交互示意稿存于 `.superpowers/brainstorm/`（不入库）；行为规格以本文为准。
> 实施后按 §13 的映射并入 [features.md](../features.md)（F20–F24）。

---

## 0. 一句话与原则

**热键定意图：⌘⇧S 圈选即搜（现状），⌘⇧X 松手即拍；拍完进左下角托盘，点开进 CleanShot
式编辑器；编辑器里的 AI chips 一键把整图（含标注）送进共享搜索面板。**

原则：与圈选共享一套冻结底座 · 零新增 TCC 常驻权限 · 零第三方 · 产物本地优先（无云、
无账号）· CleanShot 手感 · 新增字符串全部走 l10n 管线（zh-Hans 基线 + en + ja）。

## 1. 模式模型（核心心智，2026-07-16 用户拍板）

- **快捷键负责唤起哪种功能**——按键那一刻用户自己知道意图，不做模式内切换开关。
- **圈选**：选完选区**留在屏上**继续交互（搜索/翻译/可视化/编辑/截图）。
- **截图**：**松手/点击即快门**，覆盖层立刻退场，产物进托盘。
- 其余差异都是 UI 细节；两条链路在「共享搜索面板」与「截图产物管线」处互通。

## 2. 截图模式（F20）

### S1 · 触发与选取

- **全局热键**：默认 **⌘⇧X**，复用现有键帽录制器可改（避开系统占用的 ⌘⇧3/4/5）。
  - **与蓄力手势（F1，opt-in）的互斥**：蓄力计时窗口内收到自家已注册的 ⌘⇧ 前缀热键
    （⌘⇧S/⌘⇧X）→ 立即取消蓄力、按热键意图直进对应模式，避免「先闪圈选再跳截图」。
- **菜单栏**：新增「截图」「截取全屏」两项。菜单触发的全屏截图**延迟 ~180ms**（等菜单
  淡出）再抓，避免拍到菜单残影。
- **URL scheme**：`c2s://shot`（进截图覆盖层）与 `c2s://shot?mode=full`（直拍鼠标所在屏
  全屏），与 `c2s://capture` 并列，供 Raycast/Stream Deck/BTT 绑定。
- **冻结管线全复用**：预热 SCShareableContent → 鼠标所在屏 → SCScreenshotManager 单帧 →
  DisplayContext 单一坐标真源。**截图模式不跑 OCR / 条码预扫**（无选词需求，省一路开销）。
- **会话级窗口快照**：热键按下时与抓屏**并行现拉**一次 SCShareableContent 作为本次会话的
  窗口列表（长寿命 prewarm 缓存只作 fetch 未返回前的临时兜底；会话结束丢弃）——
  否则窗口高亮/命中会用到陈旧 frame 与 z-order（详见 §8 WindowPickerLayer）。
- 覆盖层视觉：轻暗化 + 十字光标 + 光标旁实时 **W×H** 尺寸标签。
- **三种选取，全部即拍**：
  - **拖拽 = 区域**：出白色 marquee（框外压暗），松手即快门。位移 < 3pt 视为点击。
  - **点击 = 整窗**：悬停窗口即微光高亮 + 阴影样式预览，点击窗口任意处即拍整窗。
    **点击落空**（未命中任何窗口，如空桌面）：**不快门、覆盖层保持**（防误触）。
  - **⏎ = 当前屏全屏**；菜单栏「截取全屏」与 `mode=full` 等价（不进覆盖层）。
- **Esc / 再按热键 = 取消**。capturing 期间重复触发去重（同 F1）。
- 与圈选互斥：同一时间只允许一个覆盖层会话；圈选会话中按 ⌘⇧X（或反之）先结束当前会话再进入新模式。

### S2 · 快门与产物

- **快门反馈**：轻闪白（跟随系统「减弱动态效果」自动省略）+ 可选快门声
  （**自带 `shutter.aiff` 进 Resources 用 NSSound 播**——系统截图音无公共 API，不依赖）。
- **产物来源（三路各自声明，勿混淆）**：
  - **区域 / 全屏**：从**冻结帧**按 DisplayContext 裁剪——所见即所得，天然不含自家 UI。
  - **整窗**：**快门时刻对活窗口单窗实抓**（透明圆角 + 无遮挡内容只能实抓，冻结帧给不了）。
    接受与冻结预览的内容漂移（视频/动画场景，与 CleanShot 一致）；目标窗口在点击时已
    关闭 → **回退**为按窗口 frame 裁冻结帧（无透明、无阴影）静默降级。
- **格式**：
  - 默认 **PNG**（保留 Retina 像素密度；可选 JPG q0.9）。
  - **窗口截图始终强制 PNG 并保留窗口自身 alpha**（圆角）；「带阴影」开关只控制合成投影。
- **剪贴板**：默认自动复制（可关）。写入 **PNG + TIFF 双 representation**
  （一批 Office/Java/Electron 系应用只认 TIFF；alpha 两者都保留）。
- **落盘**（可关）：默认目录 **`~/Pictures/Ringgo`**（非 TCC 保护路径——~/Desktop、
  ~/Documents、~/Downloads 首写会触发系统「文件与文件夹」弹窗，见 §7；用户自行改到
  Desktop 视为知情）。文件名模板默认 `Ringgo {date} at {time}`：
  `{date}` = `yyyy-MM-dd`，`{time}` = `HH.mm.ss`（点号避开冒号，跨文件系统安全）；
  同名冲突追加 ` (n)`。目录不可写/磁盘满 → 原生错误提示，产物保留在剪贴板与托盘。
- **窗口截图阴影（技术定案，见 §13）**：单窗抓取**显式** `ignoreShadowsSingleWindow = true`
  拿无阴影透明位图（不赌默认值——头文件注释含混，须以 5 行原型实测确认），再自绘合成
  投影（固定 radius/offset/opacity 常量，效果稳定可控，不依赖已弃用的 CGWindowList 截图 API）。
  - 抓取配置：`config.width/height = filter.contentRect × filter.pointPixelScale`（14.0 可用）、
    `captureResolution = .best`、pixelFormat 保持 BGRA 留 alpha、不设 `shouldBeOpaque`。
  - **sheet/子窗口版本分界**：`includeChildWindows` 是 **macOS 14.2+** API——14.2+ 显式开启
    （注意 contentRect 会随子窗口联合外接框扩大，画布尺寸跟着走，需实测）；
    14.0/14.1 单窗抓不含 sheet/popover，如实写进 §10 边界，不做二次 hack。

### S3 · Quick Access 托盘（F21）

- 快门后缩略图飞入**快门所在屏左下角**（位置可设为右下）。
- **单实例托盘**：多屏连拍时整叠迁移到最近快门所在屏（不做每屏各一叠）。
- **窗口形态**：不抢焦点浮动面板，实现按此 checklist（AppKit 三个暗坑都踩过）：
  `NSPanel(styleMask: [.nonactivatingPanel, .borderless])` ·
  `level = .screenSaver + 1`（须高于覆盖层，靠同级 order 压层不可靠）·
  `hidesOnDeactivate = false`（默认 true 会在 app 失活时凭空消失）·
  `becomesKeyOnlyIfNeeded = true` ·
  `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]`。
- **堆叠**：最新在上、错位堆叠，最多同屏显示 5 张，更多折叠成「+n」徽标；
  **点「+n」展开为可滚动纵列，再点收回**（折叠项经展开访问）。
- **单项交互**：
  - 悬停浮出动作：**✏️ 标注**（=点击）· **📌 钉图** · **💾 保存** · **×**。
  - **点击 = 打开编辑器**（若覆盖层还在，先退覆盖层再开编辑器）。
  - **拖走 = 拖出文件，成功后该项从托盘移除**（「拖走就是拿走」，对齐 CleanShot）。
    拖出走 AppKit 层（`NSViewRepresentable` 包 NSView + `beginDraggingSession`）——
    纯 SwiftUI `.onDrag` 表达不了 file promise。未落盘项**拖拽开始时现场压平写入
    scratchpad 临时文件、拖 fileURL**（比 NSFilePromiseProvider 兼容面广）；已落盘拖文件 URL。
  - 💾：落盘关闭时 = 立即按模板落盘并打勾反馈；已落盘 = 在 Finder 中显示。
  - ×：移除托盘项，**不删除**已落盘文件。
- **生命周期**：默认常驻到手动关闭；设置可选「自动收起」：默认 **5 秒**，档位 3/5/10/30 秒，
  **悬停暂停计时**（收起只是托盘项消失，产物仍在剪贴板/磁盘）。托盘项为 App 运行期状态，
  重启不恢复（「截图历史」列后续，见 §12）。

## 3. 标注编辑器（F22）

### S4 · 编辑器本体（版式对齐 CleanShot，2026-07-16 用户提供截图为准）

- 点托盘缩略图进入；**每张截图一个独立文档窗口，可多开**
  （设计展开项：若实施时要压体量，v1 可先单窗复用、多开挪后续增强）。
  标题 = 文件名（未落盘用模板名）。
- **文档生命周期**：托盘项在运行期内**持有 AnnotationDocument**——Done/× 关窗后再点
  同一托盘项、或钉图双击回编辑器，回到**同一文档、矢量对象继续可编辑**。
- **顶部工具栏**（横排，自左向右）：
  裁剪 ｜ 选择 · 空心框 · 实心框 · 椭圆 · 直线 · 箭头 · 文字 · 马赛克 · 聚光高亮 · 序号 · 画笔
  ｜ 颜色下拉 · 粗细下拉（三档，默认中档）｜ 右端 **Save as… / Done**。
  - 色板预设 6 色：红 `#EA4335`（默认）· 黄 `#FBBC05` · 绿 `#34A853` · 蓝 `#4285F4` ·
    黑 · 白，外加自定义取色器（四色沿用品牌色）。
- **AI 行**（工具栏正下方细行，Ringgo 独有）：`[🌐 翻译整图] [💬 提问] [📊 可视化] [搜索框——]`，见 S5。
- **画布**：浅灰衬底居中显示，缩放 25%–400%（⌘+/-、⌘0 适应、底部左侧「100% ▾」）。
- **底部栏**：左 = 缩放；中 = **「≡ Drag Me ≡」拖出当前画布（含标注压平；机制同 S3 拖出）**；
  右角标 = **📤 系统分享 · 📌 钉图 · ⧉ 拷贝**（CleanShot 的云上传不做——无账号原则）。
- **矢量对象模型**（2026-07-16 拍板，方案甲）：每笔标注是对象，画完可再选中、拖动、改色、
  删除；⌘Z/⌘⇧Z 走 UndoManager；**在任何导出面（保存 / 拷贝 / 拖出 / 发搜索 / 钉图 /
  系统分享）时压平**，画布内永不破坏原图。
  - **导出保真（规格真源 = 图像像素空间）**：渲染写成「(GraphicsContext, 目标像素尺寸) →
    绘制」的单一纯函数，预览与导出共用；线宽、马赛克块大小、聚光压暗一律以原图像素
    定义，预览按比例缩放——否则 5K 图导出会和预览不一致（马赛克粒度最明显）。
    马赛克像素化只对各对象矩形的裁剪区做，不做整图（省内存）。
  - **文字工具编辑态**：Canvas 只能绘不能编——编辑时在画布对应位置叠临时
    TextField/NSTextView，结束（点空白/Esc/回车）提交回矢量对象由 Canvas 接管渲染。
  - 聚光高亮 = 全图压暗、对象区域保持原亮；序号 = 自增圆形角标；
    裁剪 = 非破坏（保留原图 + 裁剪矩形，可再调）。
- **Done / Save as… / 关窗**：
  - **Done** = 压平导出 + 关窗，产物去向按设置矩阵：落盘开 → **覆盖快门时落盘的同一文件**
    （对齐 CleanShot）；剪贴板开 → 同步刷新剪贴板为压平图；**两开关都关** → 兜底写剪贴板
    并轻提示「已拷贝」。托盘项缩略图同步更新为标注后版本。
  - **Save as…** = 另存对话框（不影响原文件与开关矩阵）。
  - **×** 关窗且有未导出标注 → 问一次（保存 / 不保存 / 取消）；「不保存」不丢矢量文档
    （运行期仍挂在托盘项上，重开可继续）。

### S5 · AI chips + 共享搜索（核心差异化，2026-07-16 用户拍板）

- **发出去的是「当前画布状态」**：标注压平后的整图——用户画的红圈、箭头 AI 都看得见
  （呼应最初诉求「截图圈画好了之后直接搜索」）。
- 三枚 chip + 搜索框：
  - **🌐 翻译整图**：一次性动作，prompt 复用 F15 图片翻译（「请把这张图片里的所有文字
    翻译成{目标语言}…」），目标语言与 F10 共用同一设置。
  - **💬 提问**：聚焦搜索框；输入问题回车 = 整图 + 问题（同 F11 整屏提问机制：Lens 上传
    → vsrid 就绪自动挂 multisearch + AI Mode）。
  - **📊 可视化**：一次性动作，prompt 复用 F15 可视化。
- **管线零新轮子**：压平图按 Lens 约束降采样（长边 ≤1600、JPEG q0.85）→ 现有
  SearchService 表单上传 → **共享 ResultPresenter 面板**（同一 WKWebView dataStore、
  同一登录态/cookie、同样的可编辑药丸 + 模式 chip；PendingLensPrompt 挂起机制照用）。
- **会话边界（与 F11/F15 既有语义的分工）**：
  - **编辑器 AI 行每次发送 = 新 Lens 会话 + 重传当前压平画布**（走现有 `lensSessionURL`
    清空规则，绝不挂上一次的旧会话）。
  - **进入面板之后**的药丸编辑 / 搜索框追问，沿用 F11/F15 的**同会话**语义——图 = 发送
    那一刻的画布快照，之后在编辑器里改标注**不回溯**；要按新画布重问，回编辑器 AI 行重发。
- **单实例面板仲裁**：面板始终跟随**最近一次发起请求的窗口**重新停靠（编辑器旁右侧优先，
  遵循现有停靠规则）；新会话直接覆盖旧内容；发起窗口关闭后面板原地保留。

## 4. 钉图（F23）

### S6 · 钉图 Pin

- 入口：托盘 📌 / 编辑器底部 📌。
- 无边框置顶浮窗显示该图（含已压平标注）：初始位置 = 原截取区域的屏幕原位
  （DisplayContext 可映射时），否则鼠标所在屏中心。
  - **初始尺寸 = 原尺寸，但不超过所在屏的 50%**（超限等比缩小——否则全屏截图钉出一张
    遮满整屏的置顶窗）；窗口截图按**窗口框**对齐原位，合成阴影向外溢出。
- 交互：整窗可拖；边角拖拽等比缩放（**10%–200%**）；**双击 = 打开编辑器**（回到同一
  AnnotationDocument，见 S4 生命周期）；hover 右上浮出 ×；右键菜单 = 标注 / 拷贝 / 保存 / 关闭。
  可同时钉多张。
- 钉图窗层级 floating；**会被后续截图/圈选拍进去**（与 CleanShot 一致，不做排除——
  用户可先关钉图再截）。

## 5. 圈选模式增强（F24）

### S7 · 窗口角标（增强 ①；v2，2026-07-17 用户实测后拍板）

- ⌘⇧S 冻结后，**所有可见窗口**右下角（内缩 10pt）常驻一枚淡淡的「角标」——
  单角 L 形，与选区四角括号同一语汇（~~v1：悬停 120ms 才出的 🔍 圆钮~~
  用户实测后改：只给最前窗不够用、样式要更抽象）。窗口列表用 S1 同款**会话级快照**。
- **遮挡剔除**：角标命中区被更前窗口的 frame 盖住 → 不画（角标不能浮在别人内容上）；
  纯函数 `WindowCornerHandles.visible`（C2SCore，front-to-back 序）+ 单测。
- **悬停角标 → 该窗微光高亮**（预览「点下去选它」）；
  **点角标 = 整窗外框作为选区**（F6 矩形语义：可再调、迷你工具条照常出）
  → 直接图搜（Lens，从冻结帧按窗框裁剪——圈选路径不做单窗实抓，所见即所得优先）。
- **与截图模式的不对称是有意的**：圈选模式里轻点/拖拽已有选择语义（F4），所以只有
  角标命中区可点整窗；截图模式无轻点语义，整窗都是快门按钮。
- 角标不抢手势：笔刷/拖拽进行中整层隐藏；轻点其余位置语义不变。

### S8 · 迷你工具条 + 📸 截图（增强 ②）

- 文字选区与图片选区的迷你工具条**都**追加「📸 截图」按钮（排在现有动作之后）。
- 行为：按当前选区取图——图片选区 = 矩形原样；文字选区 = 选中词框外接框**外扩 8pt**
  （与 F15「选区类型切换/改选图片」同参数；该功能对应 commit 序号 F16，features.md
  功能表尚未单列，见 §13）——走同一条产物管线（剪贴板 + 托盘 + 按设置落盘），
  轻快门反馈，**覆盖层不退**（可能还要接着搜）。产物裁自冻结帧。
- 与 F12 ⌘C 的分工：⌘C = 只进剪贴板的轻动作（行为不变）；📸 = 完整产物（托盘、可标注、可钉）。

## 6. 设置（新增「截图」tab，现有 5 tab → 6）

| 项 | 默认 | 说明 |
|---|---|---|
| 截图热键 | ⌘⇧X | 键帽录制器，同 F13 约束（录制期间暂停全局热键） |
| 拍后复制到剪贴板 | 开 | PNG + TIFF 双 representation |
| 自动落盘 | 开 | 目录默认 `~/Pictures/Ringgo`；改到 Desktop 等 TCC 目录时提示会弹系统授权（§7） |
| 文件名模板 | `Ringgo {date} at {time}` | `{date}`=yyyy-MM-dd,`{time}`=HH.mm.ss;冲突追加 ` (n)` |
| 图片格式 | PNG | 可选 JPG（q0.9）；窗口截图始终 PNG 保留 alpha（阴影开关只控投影） |
| 窗口截图带阴影 | 开 | 关 = 无合成投影（仍透明圆角） |
| 快门声 | 开 | 自带音效（Resources/shutter.aiff）；闪白另行跟随系统「减弱动态效果」，无独立开关 |
| 托盘位置 | 左下 | 可选右下 |
| 托盘自动收起 | 关 | 开启后默认 5 秒，档位 3/5/10/30；悬停暂停计时 |

## 7. 权限矩阵

| 能力 | 权限 |
|---|---|
| 截图/整窗抓取/窗口列表 | 屏幕录制（已有，同一 TCC 授权，无新增） |
| 落盘到 `~/Pictures/Ringgo`（默认） | 无弹窗 |
| 落盘到 Desktop/Documents/Downloads（用户自选） | 首写触发系统「文件与文件夹」一次性弹窗（如实告知,不算常驻权限） |

## 8. 架构与模块（2026-07-16 拍板，方案乙：共享底座、平行模式）

**不走**现有 OverlayView 塞 `if 截图模式`（原项目 1450 行上帝对象老路，features.md §6
模块架构点名要拆的对象）。

- **共享底座（现有，抽稳接口）**：`HotkeyManager`（+⌘⇧X）· `CaptureService` ·
  `DisplayContext` · 冻结窗口 · 选区拖拽手势。
- **`OverlayMode`（search / shot）**：覆盖层由模式控制器驱动，选后行为各自派发——
  search → 选区常驻 + 搜索面板（现状）；shot → 快门 → 退场。
- **新增模块**（全部独立于覆盖层，可单独理解/测试）：
  - `WindowPickerLayer`（C2SAppKit/Overlay）：输入 = **会话级窗口快照**（S1，不许直接读
    CaptureService 长寿命缓存）→ 命中 + 高亮 + 手柄；两模式共用，动作由模式注入。
    - **z-order 命中不赌 SCShareableContent.windows 的数组顺序**（SDK 无文档保证）：
      用 `CGWindowListCopyWindowInfo(.optionOnScreenOnly)`（未弃用；弃用的只是
      CGWindowList 截图 API）拿文档保证的 front-to-back 顺序，按 windowID 对齐 SCWindow；
      过滤 = `windowLayer == 0` + 排除自家 PID + 最小尺寸阈值 + `kCGWindowAlpha > 0`。
    - **坐标转换**：SCWindow/CGWindowList 的 frame 是 CG 全局坐标（主屏左上原点、y 向下），
      DisplayContext 新增 `cgGlobal ↔ point` 双向转换作为唯一换算点——副屏在主屏上方/
      左侧（负坐标）时错位在单屏开发期看不出来，单测必须覆盖（§11）。
  - `ShotPipeline`（C2SAppKit）：裁剪/整窗图 → 剪贴板（PNG+TIFF）→ 命名模板落盘 → 托盘投递。
    纯函数部分（命名模板、裁剪几何、Retina px 映射）放 C2SCore 供单测。
  - `WindowCaptureService`（C2SAppKit）：单窗实抓（S2 配置定案）+ 阴影合成。
  - `QuickAccessTray`（C2SAppKit）：托盘面板（S3 panel checklist）+ 堆叠 + 拖出。
  - `AnnotationEditor`（C2SAppKit/Editor）：文档窗口；`AnnotationDocument` +
    `AnnotationObject`（enum：arrow/line/rect/ellipse/text/pen/highlight/mosaic/counter/crop）
    为纯模型放 C2SCore；渲染 SwiftUI Canvas（像素空间规格真源，见 S4）；UndoManager。
  - `PinWindowController`（C2SAppKit）。
  - **编辑器→搜索桥**：压平图 → 现有 `SearchService` + ResultPresenter + QueryPromptMode，
    不新写任何搜索代码。
- 菜单栏、Settings、Welcome 继续注入同一组 environment objects（F13 接线约束）。

## 9. 实施切片顺序（仿 features.md §7，先打通再加深；每片可独立验收）

1. **切片 ①「能拍能用」**：⌘⇧X → 冻结 → 区域/全屏即拍 → 剪贴板 + 落盘 + 托盘（点击暂

2. **切片 ②「圈选互通」**：F24 两增强（窗口手柄 + 迷你工具条 📸）——小而独立，

3. **切片 ③「编辑器本体」**：S4 矢量标注 + 导出压平 + Done/Save as 矩阵 + 托盘点击进编辑器。
4. **切片 ④「智能与钉图」**：S5 AI chips 桥 + S6 钉图。

## 10. 边界与错误处理

- **多屏**：覆盖层只铺鼠标所在屏（现状）；托盘单实例、整叠迁移到快门所在屏；
  钉图原位映射失败落鼠标屏中心。
- **Retina/缩放屏**：一切裁剪经 DisplayContext（point↔px↔cgGlobal 单一真源），
  禁止写死 ×2（features.md §8 老坑）。
- **窗口命中边界**：最小化/其他 Space 的窗口不在快照可见列表，天然不参与；
  全屏窗口可整窗拍；桌面/壁纸层（windowLayer ≠ 0）过滤掉。
- **自家 UI 入镜**：
  - 区域/全屏产物裁自冻结帧——marquee/手柄/尺寸标签本就不在产物里，无需处理。
  - **托盘**常驻会被连拍的第二张起拍进去：**抓冻结帧前临时隐藏托盘，快门后恢复**
    （圈选模式唤起同样适用）。
  - **钉图**声明不排除（S6，与 CleanShot 一致）。
- **整窗路径 WYSIWYG 偏差**：冻结预览与快门实抓存在时差（视频走帧、时钟走字），
  接受并声明；窗口点击时已消失 → 回退冻结帧裁剪（S2）。
- **sheet/子窗口**：14.2+ 开 `includeChildWindows`；14.0/14.1 整窗产物不含 sheet/popover
  （系统限制，如实接受）。
- **落盘失败**（目录不可写/磁盘满）：原生错误提示，产物保留在剪贴板与托盘，不丢图。
- **编辑器打开超大图**：画布渲染按需降采样预览，导出仍用原始像素（S4 像素空间规格）。
- **托盘与覆盖层并存**（圈选 📸 后）：托盘层级更高、可见不可抢焦点；点缩略图 = 退覆盖层开编辑器。
